## ADDED Requirements

### Requirement: 站点 MUST 中英双语，且英文为主

站点 MUST 为中英两种语言各出一份**完整**的产物：每版本报告页（deck / Markdown / PDF）、站点首页、跨版本对比页。英文 MUST 位于根路径（`site/index.html`、`site/<slug>/index.html`、`site/compare-*/index.html`），中文 MUST 位于同级的 `zh/` 子目录。每一页 MUST 提供通往**同一页**另一语言版本的链接，且站点内每个内部链接 MUST 指向确实存在的文件。**缺失的译文 MUST 使渲染失败并指出缺哪个键**——MUST NOT 出现空白、MUST NOT 回落到另一种语言。两种语言页面的数值与结论 MUST 来自同一份留档，即同一次运行的数据。

#### Scenario: 两种语言各有完整产物
- **WHEN** 渲染一个已留档的版本
- **THEN** 根目录与 `zh/` 下各有 deck、Markdown、PDF 三份，且三份的数值都来自该版本的同一份留档

#### Scenario: 语言互链可达
- **WHEN** 从英文页点语言切换链接，再从中文页点回来
- **THEN** 两次都到达同一页面的另一语言版本；且站点里每个内部链接（含首页的版本卡片、对比页入口）都指向存在的文件

#### Scenario: 缺译文即失败
- **WHEN** 某个键缺少英文（或中文）文案
- **THEN** 渲染以失败结束并指出缺哪个键，MUST NOT 产出留白或混用两种语言的报告

#### Scenario: 英文产物不留中文原文
- **WHEN** 浏览英文产物
- **THEN** 其正文里的文案全部是英文，含口径局限、负载是替身声明、「不可跨运行比较」这类长段落——不把长段落留作中文原文

#### Scenario: 两种语言的数字一致
- **WHEN** 对照英文页与中文页里的同一个结论
- **THEN** 两者给出同一个数字（来自同一份留档的同一次运行）

#### Scenario: 图表的文字随语言
- **WHEN** 渲染英文产物
- **THEN** 图表的标题与轴标签也是英文，且两种语言的图表文件**不互相覆盖**

## MODIFIED Requirements

### Requirement: 报告 MUST 可导出为 PDF，且与其他输出同源

报告 SHALL 能由**同一份原始数据**导出为 PDF。导出 MUST NOT 引入独立于其他输出格式的数据
处理路径——各输出格式之间的数值与结论 MUST 一致，因为它们来自同一层数据抽取。

PDF 导出 MUST 正确渲染**该份产物所用语言**的文字，并 MUST 记录实际使用的字体供复核。中文产物在运行环境中找不到可用中文字体时，导出 MUST 以失败结束并给出可执行的安装指引，MUST NOT 静默降级为无法显示中文的字体后照样产出文件。英文产物的正文（含图表内文字）MUST 限制为 **ASCII**：那套字符白名单原本是按**中文字体覆盖**逐字试出来的（实测 SimHei 缺 `µ`），把 ASCII 之外的字交给它等于把方框风险重新引进英文报告；英文出现非 ASCII 字符时导出 MUST 以失败结束并指出具体文本，以便区分「漏了翻译」与「数据本身如此」。英文产物 MUST NOT 因环境中缺少中文字体而失败。

#### Scenario: 各输出格式同源
- **WHEN** 用同一份原始数据分别渲染站点报告与 PDF
- **THEN** 两者的数值与结论一致，且都不自行解析原始数据

#### Scenario: 不重新测量即可导出
- **WHEN** 对已留档的原始数据导出 PDF
- **THEN** 导出成功且无需重新测量

#### Scenario: 中文字体缺失时明确失败
- **WHEN** 运行环境中不存在任何可用的中文字体，且渲染的是中文产物
- **THEN** 导出以失败结束，错误信息指明需要安装的字体，且不产出中文无法显示的文件

#### Scenario: 英文产物不因缺中文字体失败
- **WHEN** 运行环境中不存在任何可用的中文字体，且渲染的是英文产物
- **THEN** 导出成功（英文只用 ASCII，不需要中文字体）

#### Scenario: 英文产物出现非 ASCII 即失败
- **WHEN** 英文产物的正文里出现非 ASCII 字符
- **THEN** 导出以失败结束，并指出是哪些文本——而不是任由它可能变成方框

#### Scenario: 导出记录所用字体
- **WHEN** 导出成功
- **THEN** 导出结果或日志中记录了实际使用的字体文件，使「中文为何能正常显示」可被复核
