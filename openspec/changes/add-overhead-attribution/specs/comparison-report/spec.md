## ADDED Requirements

### Requirement: 报告 MUST 含开销归因维度，且结论 MUST 指出超出部分落在哪一段

报告 SHALL 含一个**开销归因**维度：在相同的档位与并发度下，给出被测框架与各对照方案四段（提交侧 / 手交 / 执行体 / 回程）各自的中位数，并给出**被测框架相对各对照方案的超出部分主要落在哪一段**的结论。该维度 MUST NOT 只给一个总开销数字。归因缺失、不可信或未探查时，报告 MUST 如实说明其状态，MUST NOT 省略该维度——省略会让读者以为它不存在。

#### Scenario: 维度在场且逐段给出
- **WHEN** 读取报告的开销归因维度
- **THEN** 其中按档位与并发度给出被测框架与各对照方案的四段中位数

#### Scenario: 结论指出段落而不是只给总量
- **WHEN** 读取该维度的结论
- **THEN** 结论说明超出各对照方案的部分主要落在哪一段，使读者知道下一步该看哪一处；只给一个总开销数字不满足本条

#### Scenario: 对照方案也逐段给出
- **WHEN** 某个对照方案参与归因
- **THEN** 它给出四段各自的中位数，而不是只给总开销——没有对照的分解回答不了"超出部分落在哪"

#### Scenario: 不可信或未探查时如实示人
- **WHEN** 该维度的自洽判据未通过，或本轮运行未包含归因探查
- **THEN** 报告给出该状态与原因，且不给据此得出的优化建议
